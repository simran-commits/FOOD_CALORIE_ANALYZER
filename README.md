# 🍔 Food Calorie Analyzer

A simple web-based application that helps users calculate and track calories based on food items and quantities.

## 🚀 Features

* Calculate calories based on food and quantity
* Food calorie information stored in JSON format
* Daily and weekly calorie tracking
* Weight-loss calorie estimation
* Simple and user-friendly web interface
* Responsive frontend design

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* Pandas
* JSON

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/simran-commits/FOOD_CALORIE_ANALYZER.git
```

### 2. Open the project folder

```bash
cd FOOD_CALORIE_ANALYZER
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python3 app.py
```

Open the local URL shown in the terminal.

## 🎯 Project Goal

The goal of this project is to provide a simple calorie-analysis tool where users can enter food items and quantities and get useful calorie-related information.
